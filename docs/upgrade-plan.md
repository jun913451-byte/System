# 系统升级计划

本轮升级按依赖关系推进，已完成实现与浏览器核验。未接入真实供应商和支付，以下商品、价格、订单、天气联动均为课程演示能力。

1. **单件购买与出行人（已完成）**：商品由详情页进入单件购买；支持多名常用出行人、掩码展示、同行人录入和历史复用。订单保存出行人快照，购买默认不关联行程。
2. **旅游套餐（已完成）**：套餐匹配后可查看交通、酒店和景点子项；支持一次提交套餐内交通与住宿订单，服务端计算后按合计 8 折分摊金额，景点作为游览安排展示。
3. **助手规划体验（已完成）**：新建行程支持出发日期和旅行偏好；项目栏可收起；行程全屏同时包含对话和行程安排。可用天气预报用于建议，无法取得时提示出行留意天气。
4. **图片与内容（已完成）**：补充本地酒店、景点分类图片和跨城市商品数据；交通商品不使用酒店图片。
5. **导航与响应式（已完成）**：导航栏收起动效支持减少动态效果设置；桌面、390px 窄屏及助手全屏布局已检查。
6. **核心提醒与订单协同（已完成）**：硬冲突与软冲突分别分类、持久化、排序和同步已读状态。有项目的软冲突、天气和助手回复通知会打开对应对话；硬冲突可打开订单详情。订单排序为未完成在前、已完成在最后。
7. **搜索、详情和购买路由（已完成）**：搜索提交进入独立结果页；机票和火车往返按去程、返程两步分别办理，返程沿用去程所选出行人。酒店详情、票务详情、购买页和订单列表可通过路由前进/返回。
8. **冲突统一处理（进行中）**：跨项目冲突的固定入口、消息列表和冲突管理视图已实现；项目内冲突仍留在项目对话。逐项订单提案、修改说明输入及确认后执行尚待开发；每项必须明确订单、动作和目标值，并在执行后重新读取和评估。仅可修改本地演示订单，不办理真实供应商业务、支付或退款。

## 验证记录

- `npm test`：61 项通过。
- `npm run build`：通过。
- `git diff --check`：通过；仅有 Git 的 CRLF 提示。
- Playwright 隔离数据库端到端检查：往返机票/火车票、单件购买到订单详情、酒店详情和购买路由、套餐内商品与日期、硬/软冲突通知跳转、助手项目栏收起和全屏。
- 1440px 与 390px 浏览器检查无横向溢出；减少动态效果实际生效；控制台无错误。端到端测试使用临时 SQLite，不改写 `data/demo.sqlite`。

## 明确不在本轮范围

- 不接入真实支付、供应商库存或出票/订房。
- 航班/火车延误的外部事件源尚未接入，按此前约定暂不处理。
- 旅游套餐只做匹配推荐和子商品分别办理，不生成整包订单。
- 已有行程不会仅因天气预报变化而自动改写；用户可在对话中要求调整。
