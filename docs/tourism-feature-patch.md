# 旅游功能补丁

以下是旅游套餐能力的当前实现和后续边界。

- 已有包含交通、酒店和景点的本地套餐演示数据，并可从旅游频道进入套餐详情。
- 套餐组件提供交通、酒店和景点的商品入口；子项复用对应频道的商品详情和购买页面，往返航班、酒店入住日期等套餐上下文会传到购买流程。
- 套餐支持一次提交交通与住宿订单；服务端按所选出行人数计算票价、酒店间数与晚数，并对可预订商品合计打八折后分摊到每笔订单。景点作为游览安排展示，不生成门票订单。
- 套餐数据按目的地、天数、出发城市和出行日期匹配后提供给 AI 行程助手；不匹配时不传给模型。
- 浏览器已验证套餐内机票进入通用航班详情/购买路由，并可返回套餐；套餐查看不生成订单。
- 套餐结算会分别生成交通与住宿订单，页面展示原价、折后总价和优惠金额；真实供应商库存和支付不在课程原型范围。
